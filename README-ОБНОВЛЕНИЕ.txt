TEMVITA 2.2 — инструкция по обновлению GitHub Pages
===================================================

1. ПРАЙС EXCEL
--------------
Можно загрузить Excel-файл прямо в КОРЕНЬ репозитория.
Название файла НЕ имеет значения, например:
  Прайс 2026.xlsx
  цены сентябрь.xlsx
  PRICE.xlsx
  temvita_new.xlsm

Сайт проверяет Excel-файлы в корне и выбирает тот, в котором лучше всего
распознаны товары TEMVITA и бинты NORMAL. Поэтому случайный другой Excel не
должен автоматически подменить прайс.

Для определения таблицы используются заголовки по смыслу:
  Наименование
  ...предоплат...
  ...рознич...

Дата «Цены действительны от ...» также подхватывается из прайса и выводится
внизу сайта, если она найдена.

На сайте автоматически появляется ссылка «Скачать прайс».

2. ФОТО ТОВАРОВ
---------------
Чтобы заменить фотографию товара БЕЗ изменения кода, загрузите новое фото
в КОРЕНЬ репозитория. В имени файла укажите артикул/модель товара:
  01902.jpg
  01902-new.webp
  01930.png
  50C.jpg
  50B.webp
  Teddy.jpg
  Classic.png

Допустимые форматы: JPG, JPEG, PNG, WEBP, AVIF.

Если в корне найдено подходящее фото, оно имеет приоритет над встроенным
изображением из папки images.

Для общего фото бинтов можно использовать имя, содержащее одно из слов:
  бинт / normal
Например: NORMAL-bandage.jpg

3. ВИДЕО
--------
Видео также можно загрузить прямо в КОРЕНЬ репозитория.
Для привязки к товару укажите артикул/модель в имени:
  01902.mp4
  01904-demo.mp4
  01910.webm
  50C.mp4

Сайт автоматически сформирует карточки найденных видео.
Поддерживаются MP4, WEBM, MOV, M4V.

4. WHATSAPP
-----------
Рабочий номер сайта:
  +7 775 260 73 11

В каждой карточке товара есть «Заказать в WhatsApp».
Сообщение формируется автоматически с названием товара, артикулом и
розничной ценой, указанной на сайте.

6. ВАЖНО ДЛЯ GITHUB PAGES
-------------------------
Автоматический поиск Excel, фото и видео работает через публичный GitHub API.
Репозиторий, из которого опубликован GitHub Pages, должен быть доступен для
чтения. При локальном открытии index.html сайт использует резервные данные,
поскольку локальная папка не предоставляет браузеру список файлов.

После загрузки/замены файлов GitHub Pages может показать старую версию из
кэша браузера. В таком случае обновите страницу с Ctrl+F5.

7. ПРАЗДНИЧНЫЙ МИНИ-БАННЕР
---------------------------
Баннер по умолчанию ПОЛНОСТЬЮ СКРЫТ и не занимает ни одного пикселя высоты.
Он появляется только если в КОРНЕ репозитория есть праздничная открытка.

Самый простой вариант — загрузить/заменить один файл:
  holiday.jpg
  holiday.png
  holiday.webp
  holiday.gif

Также распознаются имена, содержащие слова:
  открытка / праздник / поздравление / holiday / Наурыз / Nauryz / Республика и др.

Поддерживается и короткое видео:
  holiday.mp4
  holiday.webm

Чтобы убрать поздравление — удалите праздничный файл из корня.
После следующей публикации GitHub Pages баннер исчезнет БЕЗ пустого места.
На открытку можно нажать, чтобы открыть её крупнее.

ВАЖНО: если одновременно оставить несколько праздничных файлов, сайт выберет
файл с наиболее явным именем holiday / открытка / праздник. Рекомендуется
держать в корне только одну актуальную открытку.

8. ПРАВЫЙ КАЗАХСКИЙ ОРНАМЕНТ
----------------------------
По правому краю страницы выведена узкая полупрозрачная вертикальная полоса.
По умолчанию используется встроенный казахский орнамент.

Чтобы заменить его БЕЗ изменения кода, загрузите в КОРЕНЬ файл, например:
  ornament-right.png
  ornament-right.webp
  ornament-right.svg
  орнамент-правый.png

Сайт сам подгоняет его под узкую вертикальную полосу и делает полупрозрачным
золотистым водяным знаком. Лучше всего использовать PNG/WebP/SVG с прозрачным
фоном.

9. ОРНАМЕНТЫ ПО УГЛАМ
---------------------
Для углов используется отдельный рисунок. Его также можно заменить из корня:
  ornament-corner.png
  ornament-corners.webp
  ornament-corner.svg
  орнамент-угол.png

Один и тот же рисунок автоматически отражается и ставится в четыре угла,
масштабируется для компьютера и телефона и отображается как лёгкий золотистый
водяной знак.

Для наиболее аккуратного результата орнаменты должны иметь прозрачный фон.
Удаление пользовательского файла возвращает встроенный орнамент сайта.
